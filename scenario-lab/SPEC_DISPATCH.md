# 05 子線調度方案 v1 — 2026-10-24

## 範圍
05 現況診斷／方案比較／方法與假設。歷史票證基準、固定車次重排、B/A/H 方案三欄。同一營運日及同一批清理後票證需求。保留 3D 歷史重播，不顯示方案車輛為真實車況。不做 E 預約、D 分段、F 截短、即時調度、CP-SAT。

## 資料契約
- demand_od_time：從原始 Excel 用既有 tripsplit 清理及切班，依 date、原始 route、推估 dir、上車 hour、origin、destination 聚合 n、實扣分。另保留 source_trip 匿名日內車次索引的聚合片段，供保留原班和定位時間；不含卡號、車牌、司機號。
- 以既有重播 JSON 逐日逐班驗證車次順序、上車數、四捨五入實扣。模型實扣使用新聚合的整數分；歷史資料四捨五入元的差異另註。
- observed boarding time 不是旅客到站時刻。改搭窗口以原推估車次在上車計費站的事件時間為代理，hour 僅用於需求守恆分組。ASSUMPTION
- 同站或反向異常 OD 不編造行駛段；留在 unassigned(reason=same_station/no_compatible_trip)。無對應站時刻亦留存。
- 43、21、9 座為情境車型；容量、可用數量、燃油保修及每日成本、跨線權限都非業者實測。9 座預設 0 台且本版候選不使用。

## 模型與算法
純 JS 模組。規則產生候選：B 指定方向與離峰時窗 43/21；H 指定方向及時窗選高壓班模板 +0/1/2，偏移+15分鐘；A 選峰值最大班模板，加1班或原班調時±15分鐘。新增班無自帶需求／收入。
需求按可選班次少者、原時間、穩定鍵排序，以改搭時間差最少、原班優先的貪婪分配；必須同 route/dir、涵蓋 OD、符合時間窗及逐段容量。不宣稱最優分配；未分配不等於實際拒載。
固定車次與方案先保留未裁切的觀測峰值作壓力指標，再分配，禁止用容量截斷後的數值宣稱原本<10比例下降。
車型在整個車輛工作鏈固定。相同車型用最大匹配串接；禁跨線時分線求解。這是指定車型策略下的配置，不保證混合車型全域最少。全網車數與各車型數受上限檢核。車數超限仍顯示需求量與衝突時段，不偷偷刪班。
司機沿車鏈處理載客與空駛駕車，休息不含空駛與折返；超門檻前於端點換人，單一無法拆分工作段超限明列。是可核對候選排法，不保證最少司機；完整勞動條件未涵蓋。端點換人假設備勤駕駛可到位，未計人員接送與首末站進出庫。
成本=Σ車鏈(營運km+空駛km)×車型每km費率 + 司機成本 + Σ使用車輛每日費。固定重排與方案同邊界；歷史空駛未知。少用車的每日固定費是配置試算，不等於短期可免支出。

## 不變量及可行性
每個原始OD時段已分配+未分配=需求；分配實扣+未分配實扣=原始實扣（分）。任何候選不修改原始 T/需求。B 原始峰值<10比例保持相同，另列分配後壓力、未服務量。每段分配量<=容量。未分配不超服務底線；預設要求100%，可調但不可自動降低。fleet<=上限、各type<=可用數；不能銜接明示理由。算法未找到合格配置不等於數學不可行證明。

## 畫面與追溯
三欄表、逐班時間點、計費站間路段容量矩陣、全網車輛甘特圖（載客/新增/空駛/折返/可休息），同一結果物件渲染。變更參數立即重算；顯示日期、方向作用範圍、車型配置、資料hash及模型版本。JSON 匯出只含聚合及匿名班次，不含秘密。小幫手只解釋經白名單驗證的快照。

## 驗收
單元測試：OD/金額守恆、容量、同小時不同OD、站點不涵蓋、零時間窗、B換型、加班不增需求收入、車型不跨鏈變換、無車／低車上限診斷、門檻、無效參數拒絕、無需求。真實三日整合測試與全725日聚合對帳。瀏覽器三分頁、三情境、方向、日期、不可行、下載、甘特提示與窄螢幕。另跑既有模型與網站測試。
