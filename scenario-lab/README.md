# 潭行 6670：票證重播整合版

本目錄為網站可重建來源，從使用者「潭行3D」交接版本同步；原資料夾保持不變。上游歷史說明見 UPSTREAM_HANDOFF.md，實際網站以本文件及 SPEC_REPLAY.md 為準。

- `python3 build.py ../public/scenario-lab/index.html`：內嵌 Three.js 與壓縮重播資料，不依賴 CDN。字型可退回系統。
- `src/h_host.js`：網站分頁與暫停橋接、時間定位、內部 OpenRouter 小幫手。
- `src/e_forecast.js`：保留主站先前驗證的滾動回測、共同有效日分母、低量觀測與非負下界修正。
- 重播資料僅含每站彙總、當日匿名車輛／司機序號，不含卡號、車牌或原始司機編號。
- 2024：361 日、35,005 推估車次；2025：364 日、37,520 推估車次。
- 日期、子線選取、重播暫停／定位、甘特圖點車、站線圖、面板寬度拖曳保留上游功能。
- 車次為規則推估，位置為插值。未接 GPS。22 站是展示集合，不代表全部實體站。
- 排班採最大二分匹配及司機啟發式；不宣稱最低總成本、正式法規合規或真實節省。CP-SAT 腳本只供離線研究，網站未執行。
- 主站獨立成本頁仍為有限合成候選集合示範；不是本重播排班求解器。
