# 小幫手系統提示與輸入檢查（2026-10-23）

## 已實作

- 公開版：`hosting/lib/operations-assistant.ts`；本機API：`api/assistant.py`。
- 新增受控網站操作與數據字典：`shared/site-guide.json`。網站使用說明、下載手冊和助理共用此來源。
- 問答範圍包含本站每頁的操作、數據來源、單位、公式、好處與限制；保留內部營運定位。旅客行程／旅遊資訊頁可解釋其功能，不提供對外旅遊推薦或訂位。
- 回答先讀受控工具；使用者快照只接收有界數值，不接受系統指令或任意程式。未知資料不可補零或編造。
- 年度聚合、票證重播、預測、情境分開。3D重排和成本頁八候選是不同模型。值勤跨度不是班距；啟發式司機人數不是已證明下限。
- 教學按入口、操作、來源與單位、公式、理由、限制回答。新手先給簡要流程。
- 來源附「本站使用手冊與數據字典」；前端來源按鈕可開使用說明。
- 目前仍是單次問答，不會記住跨輪對話。追問需重述頁面或指標；未新增任意程式執行能力。

## Enter 防誤送

兩個助理入口共用 `shared/chat-input.js`：

1. `compositionstart` 記錄組字狀態。
2. 組字中、原生 `isComposing`、相容鍵碼229均不送出。
3. `compositionend` 後80毫秒防護 Safari 先結束組字再觸發Enter的次序。
4. 明確Enter送出、Shift+Enter換行、長按重複按鍵不重複送出。
5. 表單提交同樣檢查組字狀態；3D忙碌時不清掉新的草稿。

自動測試覆蓋組字狀態及事件次序；瀏覽器驗證兩個入口的換行與正常Enter送出。尚未逐一實測所有作業系統的中文輸入法。
